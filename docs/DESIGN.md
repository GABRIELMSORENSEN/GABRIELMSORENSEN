# Re:Start / G4T0XX

Direção: horror psicológico e fantasia sombria inspirados em Re:Zero. Marfim, obsidiana, ametista e vermelho seco. Molduras finas, sombras, relógios em regressão e partículas. Tipografia serifada editorial para identidade, monoespaçada para dados.

O perfil GitHub não executa JavaScript, CSS de página ou overlays HTML arbitrários. O movimento fica dentro de SVGs animados e GIFs, usando tabelas e links nativos do README. Os cartões de projetos continuam clicáveis. Texto alternativo acompanha cada imagem.

O GIF de anime tem origem e crédito no README e em SOURCES.md. A ilustração principal e as molduras são próprias. O painel usa números reais, identifica o recorte e exibe data. Repositórios privados não entram nos cartões nem nas consultas REST.

Geradores: `python scripts/art.py` recria SVGs de arte. `python scripts/metrics.py` consulta dados públicos e recria métricas. `GITHUB_TOKEN` opcional permite consultar o calendário GraphQL; nunca é gravado nos assets ou no banco público.
